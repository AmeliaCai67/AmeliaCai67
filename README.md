### 现在在做什么

- [**TAKA**（塔卡故事）](https://github.com/AmeliaCai67/TAKA_tales) — 一个给 3-6 岁孩子的 AI 原生互动有声书。孩子做选择，故事真的变；通关后导出一份只属于孩子自己的有声故事。已上线运营（2026.08），3 章中英双语 + 横屏绘本模式，安全靠一整套"红线压测"工程流水线，不靠运气。

  核心理念："我们不造神，我们造镜子：AI 不替孩子做决定，只回应孩子的决定。"

  项目在快速迭代中，欢迎提 issue 或 PR。

### 一些坚持

- **Spec 先行**：没有文档的需求不值得写代码。
- **不可能三角**：任何产品决策都要说清楚放弃了什么。
- **少做少错**：防御性策略不是懒惰，是对交付质量的尊重。
- **安全是工程，不是口号**：规则库只增不减，每次 badcase 复盘沉淀成新规则。
- **AI 是镜子，不是情感陪伴**：用它整理思绪、辅助决策，但不把主体性交出去。
