### 现在在做什么

- **TAKA** — 一个给 3-6 岁孩子的 AI 互动有声书。单页 HTML，零后端，浏览器原生 TTS + 可选 LLM 续写。核心理念："不评判孩子的选择，不说教"。
- **Project 37** — AI 数据探索工具，尝试把股市/结构化数据的自动关联分析装进一个轻量发行版。

两个项目都在快速迭代中，欢迎提 issue 或 PR。

### 一些坚持

- **Spec 先行**：没有文档的需求不值得写代码。
- **不可能三角**：任何产品决策都要说清楚放弃了什么。
- **少做少错**：防御性策略不是懒惰，是对交付质量的尊重。
- **AI 是镜子，不是情感陪伴**：用它整理思绪、辅助决策，但不把主体性交出去。
